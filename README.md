## What I work on

- **Statistical genetics** — GWAS, fine-mapping (SuSiE, FINEMAP, COJO), LD, imputation, local ancestry
- **Pipelines on HPC** — Snakemake + SLURM workflows that scale from one locus to the whole genome
- **Sequence analysis** — alignment statistics, Sanger QC, VCF harmonization
- **Research tooling with AI** — provenance tracking and remembering what worked, so analyses can be reproduced and reused

## Featured projects

| Project | What it does |
|---|---|
| [**LYNXgwas**](https://github.com/AlsammanAlsamman/LYNXgwas) | Local GWAS visualization and fine-mapping platform: loci, rsIDs, LD, a full fine-mapping suite and an interactive Manhattan/LD/gene-track viewer — all in your browser |
| [**SciWeave**](https://github.com/AlsammanAlsamman/sciweave) | Everything your analysis produces, woven into one provenance network with the data, pipelines, parameters and scripts behind it |
| [**brainny**](https://github.com/AlsammanAlsamman/brainny) | Remembers how you work with AI — captures the techniques, precautions and solutions you invent in passing so you can reuse them |
| [**alignstatplot**](https://github.com/AlsammanAlsamman/alignstatplot) | R package for sequence alignment, descriptive analysis and visualization of the results |
| [**4FinemapSnake**](https://github.com/AlsammanAlsamman/4FinemapSnake) | Snakemake pipeline for multi-locus extraction, reference harmonization, LD diagnostics and FINEMAP/SuSiE/COJO runs |
| [**SangerScope**](https://github.com/AlsammanAlsamman/SangerScope) | Sanger chromatogram QC, forward/reverse consensus assembly and NCBI identification |
| [**VCF-Harmonizer**](https://github.com/AlsammanAlsamman/VCF-Harmonizer) | SLURM scatter-gather pipeline that harmonizes VCF reference alleles against GRCh37/GRCh38 |
| [**HaploTraitR**](https://github.com/AlsammanAlsamman/HaploTraitR) | Haplotype analysis linking LD-based SNP haplotypes to variation in traits |
